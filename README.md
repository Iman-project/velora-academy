# Velora Academy

A refined and responsive school website created for a web development assignment. The project includes a Home page, About page, Programmes page, and Contact page, with CSS Flexbox and Grid layouts plus JavaScript form validation.

## Features
- Responsive layout for mobile, tablet, and desktop screens
- Semantic HTML structure
- CSS Flexbox and CSS Grid implementation
- External CSS and JavaScript files
- Contact form validation with user feedback
- Professional school branding and clear navigation

## Pages
- Home
- About
- Programmes
- Contact

## Technologies used
- HTML5
- CSS3
- JavaScript
- Google Fonts
- Unsplash images

## Project purpose
This website showcases a premium Nigerian learning academy and presents the organisation clearly through focused academic programmes, elevated branding, and a contact form for admissions enquiries.
